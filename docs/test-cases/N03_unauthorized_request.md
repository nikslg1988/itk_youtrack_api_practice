# N03. Запрос с недействительным токеном авторизации

**Тип:** Негативный

**Цель проверки:** Убедиться, что YouTrack отклоняет REST API-запросы, содержащие недействительный токен авторизации, и не предоставляет данные пользователя.

### Предусловия

1. YouTrack запущен и доступен.
2. REST API доступен.
3. Для выполнения запроса используется заведомо недействительный токен.
4. Запрос направляется к endpoint получения информации о текущем пользователе.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | GET |
| Endpoint | `/api/users/me` |
| Authorization | Bearer invalid-token |
| Accept | `application/json` |
| fields | `id,login,name` |
| Request Body | Не требуется |

**Тестовые данные**

| Параметр | Значение |
|---|---|
| Токен авторизации | `invalid-token` |

### Шаги выполнения

1. Сформировать GET-запрос к endpoint `/api/users/me`.
2. Передать заголовок Authorization со значением `Bearer invalid-token`.
3. Передать заголовок Accept со значением `application/json`.
4. Передать query-параметр `fields` со значениями `id,login,name`.
5. Отправить запрос на сервер.
6. Получить и проверить HTTP-ответ.

### Ожидаемый результат

1. Сервер возвращает HTTP-статус `401 Unauthorized`.
2. Ответ имеет формат JSON.
3. Поле `error` содержит значение `Unauthorized`.
4. Поле `error_description` содержит сообщение `Invalid token`.
5. Данные пользователя не возвращаются.
6. Доступ к защищённым ресурсам не предоставляется.

**Фактическое тело ответа:**

```json
{
    "error": "Unauthorized",
    "error_description": "Invalid token"
}
```

### Постусловия

Состояние YouTrack не изменяется. Записи и другие сущности не создаются и не изменяются.
