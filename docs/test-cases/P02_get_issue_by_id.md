# P02. Получение задачи по ID

**Тип:** Позитивный

**Цель проверки:** Убедиться, что авторизованный пользователь может получить данные конкретной задачи YouTrack по её идентификатору через REST API.

### Предусловия

1. YouTrack запущен и доступен.
2. Пользователь авторизован с помощью Permanent Token.
3. У пользователя есть права на просмотр задачи.
4. В YouTrack существует задача, доступная пользователю.
5. Известен идентификатор задачи, например `DEMO-16`.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | GET |
| Endpoint | `/api/issues/{issueID}` |
| Authorization | Bearer Token |
| Accept | `application/json` |
| fields | `id,idReadable,summary,project(id,name)` |
| Request Body | Не требуется |

**Тестовые данные:**

| Параметр | Значение |
|---|---|
| issueID | `DEMO-16` |

### Шаги выполнения

1. Сформировать GET-запрос к endpoint `/api/issues/{issueID}`.
2. Подставить идентификатор существующей задачи вместо `{issueID}`.
3. Передать токен авторизации в HTTP-заголовке Authorization.
4. Передать заголовок Accept со значением `application/json`.
5. Передать query-параметр `fields` со списком необходимых атрибутов задачи.
6. Отправить запрос на сервер.
7. Получить и проверить HTTP-ответ.

### Ожидаемый результат

1. Сервер возвращает HTTP-статус `200 OK`.
2. Ответ имеет формат JSON.
3. Ответ содержит объект одной задачи.
4. Поле `idReadable` совпадает с идентификатором, переданным в запросе: `DEMO-46`.
5. Поле `id` содержит внутренний идентификатор задачи: `3-88`.
6. Поле `summary` содержит название задачи.
7. Поле `project.id` содержит `0-0`.
8. Поле `project.name` содержит `Demo project`.

**Фактическое тело ответа:**

```json
{
    "idReadable": "DEMO-46",
    "summary": "Playwright test issue 9f0a1776-a9dc-43f7-b45a-4d98c38a57cd",
    "project": {
        "name": "Demo project",
        "id": "0-0"
    },
    "id": "3-88"
}
```

## Фактический результат ручной проверки

**Статус:** Пройден.

- HTTP-статус: `200 OK`.
- Запрошенная задача: `DEMO-46`.
- Внутренний ID задачи: `3-88`.
- Summary: `Playwright test issue 9f0a1776-a9dc-43f7-b45a-4d98c38a57cd`.
- Проект: `Demo project`.
- ID проекта: `0-0`.
- Ответ содержит все запрошенные поля: `id`, `idReadable`, `summary`, `project.id`, `project.name`.

**Вывод:** Получение задачи по ID работает корректно.

**Постусловия:** Состояние YouTrack не изменяется. Новые записи не создаются и существующие задачи не изменяются.
