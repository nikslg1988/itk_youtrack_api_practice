# N01. Получение несуществующей задачи

**Тип:** Негативный

**Цель проверки:** Убедиться, что YouTrack корректно обрабатывает запрос на получение задачи с несуществующим идентификатором и возвращает ошибку.

### Предусловия

1. YouTrack запущен и доступен.
2. Пользователь авторизован с помощью Permanent Token.
3. Токен действителен.
4. Пользователь имеет разрешение на просмотр задач.
5. Известен ключ существующего проекта.
6. Указанный идентификатор задачи не существует в YouTrack.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | GET |
| Endpoint | `/api/issues/{issueID}` |
| Authorization | Bearer Token |
| Accept | `application/json` |
| fields | `id,idReadable,summary` |
| Request Body | Не требуется |

**Тестовые данные**

| Параметр | Значение |
|---|---|
| issueID | `DEMO-999999` |

Примечание: перед выполнением теста необходимо убедиться, что задача `DEMO-999999` действительно отсутствует.

### Шаги выполнения

1. Сформировать GET-запрос к endpoint `/api/issues/{issueID}`.
2. Подставить идентификатор несуществующей задачи вместо `{issueID}`.
3. Передать действительный токен авторизации в HTTP-заголовке Authorization.
4. Передать заголовок Accept со значением `application/json`.
5. Передать query-параметр `fields` со списком запрашиваемых атрибутов.
6. Отправить запрос на сервер.
7. Получить и проверить HTTP-ответ.

### Ожидаемый результат

1. Сервер возвращает HTTP-статус `404 Not Found`.
2. Ответ имеет формат JSON.
3. Ответ содержит поле `error` со значением `Not Found`.
4. Ответ содержит поле `error_description` со значением `Entity with id DEMO-999999 not found`.
5. Данные запрашиваемой задачи не возвращаются.
6. Новые записи не создаются, существующие задачи не изменяются.

**Фактическое тело ответа:**

```json
{
    "error": "Not Found",
    "error_description": "Entity with id DEMO-999999 not found"
}
```

### Постусловия

Состояние YouTrack не изменяется. Тест не создаёт и не изменяет какие-либо сущности.
