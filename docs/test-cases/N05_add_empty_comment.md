# N05. Добавление пустого комментария

**Тип:** Негативный

**Цель проверки:** Убедиться, что YouTrack корректно обрабатывает попытку добавления комментария с пустым текстом и не создаёт некорректную запись.

### Предусловия

1. YouTrack запущен и доступен.
2. Пользователь авторизован с помощью Permanent Token.
3. Токен действителен.
4. У пользователя есть разрешение Create Comment.
5. В YouTrack существует задача, доступная пользователю.
6. Известен идентификатор задачи.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | POST |
| Endpoint | `/api/issues/{issueID}/comments` |
| Authorization | Bearer Token |
| Accept | `application/json` |
| Content-Type | `application/json` |
| fields | `id,text,author(id,login),created` |
| Request Body | JSON с пустым значением text |

**Тестовые данные**

| Параметр | Значение |
|---|---|
| issueID | Идентификатор существующей задачи |
| text | Пустая строка `""` |

**Пример тела запроса:**

```json
{
    "text": ""
}
```

### Шаги выполнения

1. Выбрать существующую задачу и определить её идентификатор.
2. Получить список комментариев задачи и зафиксировать их количество.
3. Сформировать POST-запрос к endpoint `/api/issues/{issueID}/comments`.
4. Передать действительный токен авторизации в HTTP-заголовке Authorization.
5. Передать заголовки Accept и Content-Type со значением `application/json`.
6. Сформировать JSON-тело запроса с пустым значением поля text.
7. Отправить запрос на сервер.
8. Получить и проверить HTTP-ответ.
9. Повторно получить список комментариев задачи.
10. Убедиться, что новый комментарий не появился.

### Ожидаемый результат

1. Сервер возвращает HTTP-статус `400 Bad Request`.
2. Ответ имеет формат JSON.
3. Поле `error` содержит значение `bad_request`.
4. Поле `error_description` содержит сообщение `Comment can't be empty.`.
5. Новый комментарий не создаётся.
6. Количество комментариев задачи не изменяется.
7. Существующая задача и её комментарии остаются без изменений.

**Фактическое тело ответа:**

```json
{
    "error": "bad_request",
    "error_description": "Comment can't be empty."
}
```

### Постусловия

Состояние YouTrack не изменяется. Новые комментарии не создаются, существующие комментарии и задачи остаются без изменений.
