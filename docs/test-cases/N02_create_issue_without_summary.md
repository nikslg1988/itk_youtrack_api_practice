# N02. Создание задачи без обязательного поля Summary

**Тип:** Негативный

**Цель проверки:** Убедиться, что YouTrack отклоняет запрос на создание задачи, если в теле запроса отсутствует обязательное поле `summary`.

### Предусловия

1. YouTrack запущен и доступен.
2. Пользователь авторизован с помощью Permanent Token.
3. Токен действителен.
4. У пользователя есть разрешение Create Issue в целевом проекте.
5. Существует проект, в котором разрешено создание задач.
6. Известен внутренний ID целевого проекта.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | POST |
| Endpoint | `/api/issues` |
| Authorization | Bearer Token |
| Accept | `application/json` |
| Content-Type | `application/json` |
| Request Body | JSON без обязательного поля `summary` |

**Тестовые данные**

| Поле | Значение |
|---|---|
| project.id | Внутренний ID существующего проекта |
| description | Negative API test: issue without summary |
| summary | Не передаётся |

**Пример тела запроса:**

```json
{
    "description": "Negative API test: issue without summary",
    "project": {
        "id": "Внутренний ID проекта"
    }
}
```

### Шаги выполнения

1. Сформировать POST-запрос к endpoint `/api/issues`.
2. Передать действительный токен авторизации в HTTP-заголовке Authorization.
3. Передать заголовки Accept и Content-Type со значением `application/json`.
4. Сформировать JSON-тело запроса с корректным ID существующего проекта, но без поля `summary`.
5. Отправить запрос на сервер.
6. Получить и проверить HTTP-ответ.
7. Проверить, что задача не была создана.

### Ожидаемый результат

1. Сервер возвращает HTTP-статус `404 Not Found`.
2. Ответ имеет формат JSON.
3. Ответ содержит поле `error` со значением `Not Found`.
4. Ответ содержит поле `error_description` со значением `Entity with id DEMO-999999 not found`.
5. Данные запрашиваемой задачи не возвращаются.
6. Новые записи не создаются, существующие задачи не изменяются.

**Фактическое тело ответа:**

```json
{
    "error": "Not Found",
    "error_description": "Entity with id DEMO-999999 not found"
}
```

### Постусловия

Состояние YouTrack не изменяется. Новые задачи не создаются, существующие задачи не изменяются.
