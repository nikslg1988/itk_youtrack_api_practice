# P01. Получение списка задач

**Тип:** Позитивный

**Цель проверки:** Убедиться, что авторизованный пользователь может получить список задач YouTrack через REST API.

### Предусловия

1. YouTrack запущен и доступен.
2. Пользователь авторизован с помощью Permanent Token.
3. У пользователя есть права на просмотр задач.
4. В YouTrack существует хотя бы одна задача, доступная пользователю.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | GET |
| Endpoint | `/api/issues` |
| Authorization | Bearer Token |
| Accept | `application/json` |
| fields | `id,idReadable,summary,project(name)` |
| `$top` | `5` |
| Request Body | Не требуется |

### Шаги выполнения

1. Сформировать GET-запрос к endpoint `/api/issues`.
2. Передать токен авторизации в HTTP-заголовке Authorization.
3. Передать заголовок Accept со значением `application/json`.
4. Передать query-параметр `fields` со списком необходимых атрибутов задачи.
5. Передать query-параметр `$top` со значением `5`.
6. Отправить запрос на сервер.
7. Получить и проверить HTTP-ответ.

### Ожидаемый результат

1. Сервер возвращает HTTP-статус `200 OK`.
2. Ответ имеет формат JSON.
3. Тело ответа представляет собой список задач.
4. Количество возвращённых задач не превышает 5.
5. Каждая возвращённая задача содержит следующие атрибуты:
   - `id` — внутренний идентификатор;
   - `idReadable` — отображаемый идентификатор задачи;
   - `summary` — название задачи;
   - `project.name` — название проекта.

6. Ответ не содержит ошибок обработки запроса.

## Фактический результат ручной проверки

**Статус:** Пройден.

- HTTP-статус: `200 OK`.
- API вернул список задач.
- При параметре `$top=5` получено 5 задач.
- Каждый элемент ответа содержит поля `id`, `idReadable`, `summary`, `project.name`.
- Фактический результат соответствует ожидаемому.

**Вывод:** Получение списка задач работает корректно.

**Постусловия:** Состояние YouTrack не изменяется. Новые записи не создаются и существующие задачи не изменяются.
