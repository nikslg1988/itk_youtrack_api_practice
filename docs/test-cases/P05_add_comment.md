# P05. Добавление комментария к задаче

**Тип:** Позитивный

**Цель проверки:** Убедиться, что авторизованный пользователь может добавить комментарий к существующей задаче YouTrack через REST API.

### Предусловия

1. YouTrack запущен и доступен.
2. Пользователь авторизован с помощью Permanent Token.
3. У пользователя есть разрешение Create Comment.
4. В YouTrack существует задача, доступная пользователю.
5. Известен идентификатор задачи.

### Параметры запроса

| Параметр | Значение |
|---|---|
| HTTP-метод | POST |
| Endpoint | `/api/issues/{issueID}/comments` |
| Authorization | Bearer Token |
| Accept | `application/json` |
| Content-Type | `application/json` |
| fields | `id,text,author(id,login,name),created` |
| Request Body | JSON с текстом комментария |

**Тестовые данные**

| Параметр | Значение |
|---|---|
| issueID | Идентификатор существующей задачи |
| text | Уникальный текст тестового комментария |

**Пример тела запроса:**

```json
{
    "text": "API test: adding a comment to an issue"
}
```

### Шаги выполнения

1. Выбрать существующую задачу и определить её идентификатор.
2. Сформировать POST-запрос к endpoint `/api/issues/{issueID}/comments`.
3. Передать токен авторизации в HTTP-заголовке Authorization.
4. Передать заголовки Accept и Content-Type со значением `application/json`.
5. Сформировать JSON-тело запроса с текстом комментария.
6. Отправить запрос на сервер.
7. Получить и проверить HTTP-ответ.
8. Извлечь идентификатор созданного комментария из ответа.
9. Выполнить GET-запрос к созданному комментарию и проверить его содержимое.

### Ожидаемый результат

1. Сервер успешно обрабатывает запрос.
2. Ответ имеет формат JSON.
3. Ответ содержит идентификатор созданного комментария (`id`).
4. Поле `text` содержит текст, переданный в запросе.
5. Поле `author` содержит информацию об авторе комментария.
6. Поле `created` содержит время создания комментария.
7. Повторный GET-запрос возвращает созданный комментарий с переданным текстом.
8. Комментарий связан с указанной задачей.
